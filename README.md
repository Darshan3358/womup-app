# Worm Up — Customer App (26 Screens)

Complete React Native (Expo SDK 57 + TypeScript) customer application built strictly to brand wireframes and specifications.

## 🎨 Brand Design System
- **Deep Navy**: `#05062A` (Header, Dark Accents, Backgrounds)
- **Hot Pink**: `#F562AF` (Primary CTA, Highlights, Badges)
- **Purple**: `#8364E6` (Gradients, Secondary Buttons, Badges)
- **Indigo Blue**: `#515FEA` (Accents, Navigation Icons)
- **Pure White**: `#FEFEFE` / `#FFFFFF`

## 📱 Features & Highlights
- **Full 26-Screen Interactive Architecture**:
  - `S01` to `S05`: Splash & Onboarding Flow
  - `S06` to `S11`: Authentication, OTP, Account Creation, Referral, Location & Address
  - `S12` to `S15`: Home, Categories, Subcategories, Product Listing
  - `S16` to `S18`: Product Details, Search, Filter & Sort
  - `S19` to `S22`: Cart, Checkout, Shopping Coin Redemption, Payment Options
  - `S23` to `S26`: Order Placed, Live Order Tracking, Order History, Account / Profile
- **Real HD Product Packaging Images**:
  - Packshots for Fortune Basmati Rice, India Gate Basmati Rice, Daawat Rozana Rice, Fortune Sunlite Sunflower Oil, Amul Milk, Aashirvaad Atta, Tata Salt, and Maggi Noodles.
- **Smart Cart & Shopping Coins System**:
  - Live subtotal, discounts, and real-time shopping coin deductions.
- **Reliable Back Navigation**:
  - Splash screen is never navigated back to; back buttons gracefully navigate up the stack.
- **Universal Android APK Support**:
  - Ready for internal distribution across all Android devices.

## 🚀 Running Locally
```bash
npm install
npx expo start
```

## 📦 Building Universal Android APK
```bash
npx eas-cli build --platform android --profile preview
```
